# Practice Mode

Practice работает независимо от 48 уроков Learning. На главной странице Practice пять тренажёров, последние настройки каждого и восстановление незавершённой тренировки. Быстрый старт открывает готовую сессию; звук включается отдельным нажатием Start. Восстановленная сессия всегда открывается на паузе.

## Возможности

| Тренажёр        | Что можно тренировать                                                                                                               |
| --------------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| Degree          | Арабские/римские ступени, ступень + аккорд, названия; бас, трезвучия, септаккорды, расширения, обращения, смешанные задания         |
| Chord           | 36 типов аккордов, гармонические и изолированные задания, 14 способов расположения, выбор категорий и отдельных типов               |
| Style           | Worship 25, Gospel 20, Jazz 20, Pop 20, Blues 10 оригинальных прогрессий; каждый стиль включает мажор и минор                       |
| Fill & Run      | 10 типов филлов, 7 комбинаций гамм/паттернов; текущий и целевой аккорды, разрешение в аккордовую ноту, два контекста демонстрации   |
| Scale & Pattern | Гаммы Learning, натуральный/гармонический минор, P1–P10, направления, случайные паттерны, 1–3 октавы, повторения, одна или две руки |

Общие настройки: 12 центров, набор тональностей, случайный порядок и квинтовый круг; BPM 30–200 с шагом 1 и ползунком; 4/4, 3/4, 6/8, 2/4; смена через долю, две доли, 1/2/4 такта или вручную; 5/10/15/20/30/60 минут либо без ограничения; предпросмотр 0/1/2/4 задания; пять уровней подсказок.

В 6/8 BPM означает **четверть с точкой**, метроном играет две группы по три восьмых. Обычная восьмая занимает 1/3 пульса, четверть — 2/3. Длительность Scale определяется всей выбранной последовательностью и числом повторений. Fill занимает не меньше восьми пульсов, чтобы исходная гармония, подход и разрешение оставались слышимыми; его отдельная демонстрация — двухтактовая фраза 4/4. Эти особенности указаны в настройках.

При выборе Jazz/Blues интерфейс предлагает уровень не ниже 3: в библиотеке эти стили используют септаккорды. Несовместимые ограничения показывают причину и не запускают генерацию. Изолированный режим разрешает произвольные выбранные типы. Пустой набор типов означает все доступные на уровне; заданный набор не расширяется автоматически.

## Гармония и подсказки

`src/core/practice` содержит чистые типы, аккорды, голосоведение, генератор, сессии и статистику. Определения прогрессий и P1–P10 передаются через `PracticeLibrary` из адаптера `features/practice/library.ts`; core не зависит от React, Dexie или определения программы.

Гармонический генератор выбирает целые совместимые фразы с весами стиля и перехода между фразами. Случайность воспроизводится по seed. Режимы: фиксированная фраза, взвешенная случайная генерация, адаптивная генерация и явно свободный random. Последнее задание фразы связано с фактическим первым заданием следующей, включая подсказку, голосоведение и предыдущий аккорд. Очередь ограничена; длинная сессия не накапливает все задания в памяти.

Открытие подсказки останавливает тренировку и сохраняет текущее задание. Доступны состав, формула, функция, клавиатура, альтернативные расположения и общий `MusicalExamplePlayer`: Play/Pause/Stop, loop, медленное воспроизведение, точный BPM и пошаговый разбор. Возобновление повторяет текущее задание с отсчётом либо переходит к следующему. Демонстрации Practice сохраняют тональность и гармонический контекст задания; другую тональность выбирают в конфигурации. Клавиши используют общие настройки подписей; MIDI-номера можно включить отдельно.

Расширенные аккорды распределяются между руками, чтобы не требовать растяжки более октавы в одной руке. Rootless означает расположение **правой руки** без основного тона; отдельный бас остаётся доступен в левой руке/басовом канале. Третье обращение и Drop 2 требуют не менее четырёх тонов; shell требует терцию и септиму. Альтерации, обращения, slash bass и транспозиции проверяются тестами.

## Аудио и голос

Один `AudioService` и один Tone Transport обслуживают Learning и Practice. Practice использует отдельные шины metronome/bass/harmony/melody/voice с mute и громкостью. По умолчанию включён только метроном. События назначаются по аудиочасам; React получает отложенные кадры через Tone Draw. Остановка удаляет расписание, отпускает ноты, прекращает речь и отменяет устаревшую подсветку.

В обычном размере шаг transport — 1/12 четверти. В 6/8 внутренний темп четвертей равен 1,5 пользовательского BPM, а шаг движка — 1/18 четверти с точкой. Это даёт точную сетку для четвертей, восьмых, триолей и шестнадцатых без `setInterval` как музыкальных часов. Изменение BPM применяется к тому же transport.

18 локальных WAV содержат EN one–seven/flat/sharp и PL jeden–siedem/bemol/krzyżyk. На экране тренировки есть переключатель «Голос» и кнопка «Проверить голос»: она включает голос, восстанавливает ненулевую громкость и произносит текущую ступень без запуска таймера. Язык и момент объявления выбираются в настройках тренировки. Речь возможна при смене, за одну или две доли, либо выключена. При скрытом предпросмотре без разрешения на опережение, а также при ручной смене, произносится текущая ступень в момент смены. На быстром темпе занятый речевой канал пропускает новую подсказку вместо накопления очереди и наложения слов. Отсутствующий файл даёт понятную ошибку; голос можно выключить и продолжить.

«Подсказка» на основном экране — переключатель клавиатуры и звука примера. Для аккордов показываются расположения обеих рук, включая до старта и на паузе; включение даёт сразу послушать текущий аккорд, а во время игры пример меняется вместе с заданием. Схемы рук разделены, чтобы длинный диапазон баса и мелодии не уменьшал подписи на телефоне. Выключение скрывает схемы и гасит каналы bass/harmony/melody; голос и метроном управляются независимо. Режимы keyboard/full и музыкальные каналы сохраняются в прежней конфигурации без миграции базы. Подробная демонстрация и повтор с отсчётом доступны отдельно через «Разбор». В быстром старте настройки «Клавиши и звук примера» и «Озвучивать ступени» только сохраняют выбор; звук запускается нажатием на экране тренировки.

Файлы, измеренные длительности и SHA-256: `public/audio/voice/manifest.json`. Лицензии и закреплённые источники моделей: `public/audio/voice/LICENSE.txt`. Офлайн-приложению Python/Piper не нужны. `scripts/generate-voices.py` — воспроизводимая подготовка ресурсов разработчиком; модели и временные результаты не входят в репозиторий. `node scripts/verify-voices.mjs` проверяет WAV, хеши, сигнал, отсутствие clipping и длительность <0,8 с.

AudioContext разблокируется нажатием. Уход в фон, потеря фокуса или прерывание контекста ставят сессию на паузу. Wake Lock запрашивается только во время игры и не является гарантией фоновой работы на iOS. Браузер без Web Audio показывает сообщение, сохраняя доступ к настройкам и истории.

## Сохранение и статистика

Dexie v3 добавляет `trainerSessions` и `difficultTasks`, сохраняя существующие таблицы Learning и ID. Настройки находятся в `settings` под `practice-config-*`; незавершённая сессия сохраняется примерно каждые пять активных секунд, при паузах и действиях. В завершённой записи сохраняются статистика и контекст, а лишние будущие примеры удаляются из снимка. Резервная копия v2 содержит новые необязательные массивы и принимает старые копии без них; импорт валидируется и выполняется атомарно.

Hard сохраняет тональность, ступень/аккорд, расположение, соседние аккорды, тип филла, BPM, стиль и исходную фразу. Адаптация повышает вес целой подходящей фразы, сохраняя её гармонический смысл. Сброс отметок начинает адаптацию заново, сохраняя историю.

Активное время не включает отсчёт, паузы и демонстрации. Средний BPM взвешен по активному времени. История показывает завершённые и приостановленные сессии; агрегаты считают завершённые за сегодня/7/30 дней/всё время. Есть задания, аккорды, переходы, тональности, типы, подсказки и трудные контексты. Отсутствие Hard не считается правильной игрой; оценка точности без MIDI не выдумывается.

## PWA и проверки

Service worker включает код, программу, пианино и оба языка. Индикатор готовности проверяет все аудиоресурсы; можно заранее скачать их. Обновление приложения не предлагается внутри урока или сессии Practice. Портретная и горизонтальная компоновки поддерживаются manifest и CSS.

```sh
npm ci
npm run typecheck
npm run lint
npm test
npm run build
node scripts/verify-voices.mjs
npx playwright install chromium webkit
npm run test:e2e
```

Playwright проверяет production-сборку и запускает собственный preview на 4174. На Windows WebKit не предоставляет Web Audio: звуковые сценарии явно пропускаются, а загрузка пяти конфигураций, сохранение и понятная ошибка отсутствующего API проверяются. Chromium выполняет все сценарии локально; GitHub Actions на Linux запускает оба браузера полностью. Реальный iPhone требует отдельной аппаратной проверки. Подробности — `VERIFICATION.md`.
